How it works

Three steps, all inside CI

The Action stays deliberately thin — no headless browser, no LLM key, no Chromium in your runner. All of that lives server-side.

1

Compress the diff

The Action filters changed files by pattern (routes, schema, migrations), strips comments and log lines, and sends only structural signal — never full file contents.

2

Generate & validate

The ArchLens API checks your quota, asks an LLM for strict Mermaid syntax, validates it against an allow-list before rendering anything, and caches by content hash.

3

Render & post

The diagram is rendered to SVG server-side and posted — or updated in place — as a single PR comment. Push again with no structural change, and it's served from cache.

Legal & trust

The fine print

ArchLens only ever sees a compressed, structural slice of a diff — never a full repo, never runtime data, never your end users' information. The policies below cover what that means in practice.

Privacy Policy

What we collect · what we don't

Before a diff ever reaches an LLM, the GitHub Action strips it down to structural signal — changed route paths, schema/migration names, function and class identifiers — and discards comments, log lines, and full file bodies. That compressed payload, not your source code, is what's sent for diagram generation.

  • Account data: GitHub org/repo identifiers, billing email, and subscription tier, stored in Supabase.
  • Processors: Anthropic and OpenAI (diagram generation), Stripe or Razorpay (billing only — we never see full card details), Supabase (storage), Vercel (hosting).
  • Caching: generated diagrams are cached by content hash to avoid re-billing identical diffs; cached output can be cleared on request.
  • Never collected: your end users' personal data, database contents, secrets, or credentials.

Terms of Service

What you're actually buying

ArchLens is a GitHub Action plus a hosted API that generates an architecture diagram from a pull request's diff and posts it as a PR comment. Plans: free on public repos, $12/mo per private repo, $29/mo per GitHub org — billed monthly, auto-renewing until cancelled.

  • Each plan has a monthly diagram quota; going over it produces a soft warning comment, never a failed CI run, unless you opt into fail-on-error.
  • Diagrams are AI-generated and meant as a review aid, not a verified source of truth — always confirm structural claims against the actual diff.
  • No reverse-engineering the rendering pipeline, and no splitting one org across multiple accounts to bypass quota.
  • Either side may end the relationship at any time; access continues through the period already paid for.
